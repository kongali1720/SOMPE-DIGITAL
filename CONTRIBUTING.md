# Contributing to SOMPE-DIGITAL

Thank you for contributing to SOMPE-DIGITAL.

## Development Principles

Contributions should prioritize:

- Reliability
- Security
- Maintainability
- Accessibility
- Performance
- Privacy
- Local economic impact
- Open and collaborative development

## Workflow

1. Fork or clone the repository.
2. Create a dedicated branch.
3. Make focused changes.
4. Test the changes locally.
5. Update documentation when necessary.
6. Submit a pull request.

## Commit Messages

Use clear and descriptive commit messages.

Examples:

feat: add merchant registration
fix: resolve marketplace search issue
docs: update architecture documentation
security: improve authentication validation
refactor: simplify business profile service

## Pull Requests

Pull requests should explain:

- What changed
- Why it changed
- How it was tested
- Any known limitations

Large architectural changes should be discussed before implementation.
