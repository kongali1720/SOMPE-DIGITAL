# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SOMPE-DIGITAL, please report it
responsibly before publicly disclosing the issue.

Please provide:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Relevant logs or screenshots when safe to provide
- Suggested mitigation, if available

Do not include passwords, private keys, API keys, personal data, or other
sensitive credentials in vulnerability reports.

## Security Principles

SOMPE-DIGITAL aims to implement:

- Secure authentication
- Role-based access control
- Data protection
- Audit logging
- Secure API design
- Secrets management
- Dependency security
- Infrastructure hardening
- Privacy by design

## Responsible Disclosure

Security researchers are encouraged to provide sufficient information to
reproduce and validate reported issues.

Please do not perform destructive testing, data exfiltration, denial-of-service
testing, or unauthorized access against systems operated by SOMPE-DIGITAL.
